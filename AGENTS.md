# Codex instructions
- Write code and comments in English; user-facing UI text in Spanish.
- Keep Digifort servers and credentials private; never commit secrets, IP lists, XML responses containing sensitive details, or production data.
- Preserve the distinction between camera Active, Working and server unreachable.
- Use small, reviewable changes with tests and conventional commits.
- Do not expose the application to the public internet until authentication, HTTPS, authorization, and security review are complete.
- Keep Docker Compose as the local deployment entrypoint.
- For changes to the API, update relevant tests and documentation.
